# 订阅拉取代理架构

本文档说明 singbox-dashboard 在**拉取订阅数据**时的网络路径（直连 / 内置代理 / 外部代理），
以及容器与宿主机之间的代理隔离关系。

> 注意：本文只涉及"拉取订阅 HTTP 请求"的代理路径。
> **节点流量的转发（真正的翻墙流量）由 sing-box 直接连接节点服务器，与本文所述代理无关。**

## 一、三种拉取模式

| 模式 | 触发条件 | 请求路径 |
|------|----------|----------|
| 直连 | 订阅未勾选"使用代理" | 容器 → 目标服务器（不经任何代理） |
| 内置代理 | 勾选"使用代理"且**未配置外部代理** | 容器 → 容器内 sing-box mixed:2080 → 当前订阅节点出口 → 目标服务器 |
| 外部代理 | 勾选"使用代理"且**配置了外部代理** | 容器 → 外部代理（如宿主机 Clash）→ 目标服务器 |

```
直连：      [backend容器] ────────────────→ 订阅服务器
内置代理：  [backend容器] → [sing-box :2080] → 节点出口 → 订阅服务器
外部代理：  [backend容器] → [宿主机/其他机器 Clash] ─────→ 订阅服务器
```

- 每个订阅独立设置"使用代理"（前端勾选框 / `use_proxy` 字段）
- 外部代理与 UA 一样是**全局设置**，持久化在 `subscriptions.json` 的
  `fetch_proxy` 字段；未设置时回退到环境变量 `FETCH_PROXY`（默认空）

## 二、外部代理的作用与典型场景

外部代理解决的是**"首次使用"**问题：

1. 全新部署，容器内 sing-box 还没有任何订阅/节点
2. 此时"内置代理"不可用（没有节点可出口）
3. 如果目标机场封锁了你的直连 IP（或被 Cloudflare 拦截），
   就需要先配一个外部代理来拉取第一个订阅

配置方法：

- **页面**：订阅页 → 添加订阅卡片 → "外部代理（可选）" → 保存设置
- **环境变量**：`FETCH_PROXY`（如 `http://172.17.0.1:7890`），容器重启前生效
- 拉取顺序：页面设置 `fetch_proxy` > 环境变量 `FETCH_PROXY` > 空（走内置代理）

外部代理地址示例（**请替换为你自己的代理**）：

```
http://172.17.0.1:7890      # docker0 网关 = 宿主机上的 Clash（Linux 常见）
http://192.168.1.100:7890   # 局域网内另一台机器的 Clash（按你的环境修改）
http://127.0.0.1:7890       # 仅 network_mode: host 时可用
```

> ⚠️ 代理地址是**部署环境相关的私人配置**，项目默认值为空，请勿把
> 个人代理地址写死进代码或提交到仓库。

## 三、内置代理（sing-box）

勾选"使用代理"且未配置外部代理时，拉取请求走
`http://127.0.0.1:2080`——这是**同一容器内** sing-box 的 mixed 入站端口
（容器内固定 2080，宿主机关联端口由 `SINGBOX_MIXED_PORT` 配置）。

含义：订阅通过"当前已应用的订阅节点"出口拉取，适用于
"本机 IP 被机场封禁、但节点可用"的场景。

## 四、容器与宿主机代理隔离

- Docker 容器的网络环境与宿主机隔离，**宿主机 shell 的
  `HTTP_PROXY`/`HTTPS_PROXY` 环境变量不会传入容器**
- Go 的 `http.Transport` 在 `Proxy` 字段为 nil 时会自动回落读取容器内的
  `HTTP_PROXY`/`HTTPS_PROXY` 环境变量；后端代码在直连模式**显式禁用了
  环境变量代理**（`Proxy = func() { return nil }`），确保直连真正直连
- 如果容器内出现了代理环境变量（如 compose 中配置），直连模式不受影响

## 五、UA 与 403 拦截

部分机场在 Cloudflare 上按 User-Agent 拦截非订阅客户端（curl/浏览器/Go
默认 UA 均返回 403）。订阅页可全局设置拉取 UA（默认
`mihomo.party/v2.0.0 (clash.meta)`，持久化于 `fetch_ua` 字段，回退环境
变量 `FETCH_USER_AGENT`）。

## 六、故障排查

| 现象 | 可能原因 | 排查 |
|------|----------|------|
| 拉取返回 403 且内容含 Cloudflare | UA 被拦截 | 换订阅客户端 UA |
| 勾选代理后拉取超时 | sing-box 无可用节点 / 外部代理不可达 | 检查节点状态；临时改直连测试 |
| 直连拉取超时但浏览器可开 | 本机 IP 被机场封禁 | 勾选代理（内置或外部） |
| 直连模式仍走代理 | 容器内有 HTTP_PROXY 环境变量 | `docker exec <backend> env \| grep -i proxy`；新版代码已显式禁用 |
